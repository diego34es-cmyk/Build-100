● LOCAL

草稿只存在本机。表单、粘贴和预览不上传。页面仍会加载 beacon.js，不声称整页零网络。

01 标题、摘要、详情 顺序钉死 llmstxt.org：# Title → 可选 > summary → 可选 details（无标题）→ ## 分区 → 最后一块 ## Optional。空字段整段不出现。
02 主分区 每个 H2 是自定义分区名 + - [title](url) 或 - [title](url): note。标题或 url 空则该行不输出。分区名不得叫 Optional（大小写不敏感）——撞名进 Optional 桶。
03 Optional 块 保留名，只有一块：标题必须是 Optional，放在最后，下面只有链接，没有嵌套分区名。开关关或无链接 → 整块不出现。
04 预览 llms.txt 只读文本。下载文件名锁死 llms.txt。下载前标题必须非空。

05 粘贴解析 尽力认：H1、紧随的 blockquote、到首个 H2 前的 details、H2 下 - [t](u) / - [t](u): note、## Optional。YAML / H3 / 代码块 / 非列表段落进「自定义保留」，原样拼在生成结果尾部，不包 HTML 注释。

自定义保留 拼在生成结果后面。可编辑。套用预设会清空此框。

长按或右键保存。分享图只有文案，不把完整 llms.txt 画进去。
