● LOCAL

bot 表烘焙在本页。勾选与粘贴内容不上传。页面仍会加载 beacon.js，不声称整页零网络。

01 AI 爬虫 每行 Allow / Disallow / 忽略。忽略则不写该 UA。Google-Extended / Applebot-Extended 不挡 Googlebot / Applebot 搜索。「全拦 AI」只对表内 token 各写一块 Disallow: /，不会生成通配代理。
02 预览 robots.txt Allow 写成 Allow: / · Disallow 写成 Disallow: /（禁止空的 Disallow:，空等于放行）。块顺序跟表，块间空行。

03 粘贴合并 仅「单个已知 UA + 整站 Allow: / 或 Disallow: /」写入勾选（UA 大小写不敏感）。通配代理、Sitemap / Host / Crawl-delay、多 UA 共用块、带路径规则 → 原样进「自定义保留」。已知 UA 从 extras 剥掉；勾选覆盖同名块。

自定义保留 拼在 AI 块后面。输出时会剥掉表内 UA，同一 UA 不会出现两次。预设不碰这框。

长按或右键保存。分享图只有文案，不把完整 robots.txt 画进去。
