# 需求模型

只保留：**≥2 个已存在项目**或**同一痛点反复出现**。其余兴趣记在「不需要」。

## 保留

### N1 纸面金融结构（不算账就亏、但绝不能下单）

- 支持：004 赔率叙事、005 扫尾盘、008 已付月费、009 推迟储蓄、012 复利/赔率/杠杆、002 退休路径。
- 反复：用户规则里的网格/期权/REIT 也是「先算清楚」；红线禁止实盘。
- 产品形状：本地计算器 + 冻结数据 + fixture。不是券商。

### N2 一人旅居行政（西语表格 × 中文脑子）

- 支持：011 NIE/租房/回国、006 租房对比/打包、007 马德里购买力。
- 反复：本次任务点名 Spanish admin/housing paperwork。
- 产品形状：清单/对照/打印。不代填政府网、不抢cita。

### N3 用现成 AI 做小工具，而不是做「Agent 平台」

- 支持：001 订阅组合、003 提示词扩写、010 决策纸；整个 BUILD-100 工作流。
- 反复：related interests「AI agents automation」在本仓体现为 **自动化自己的发布/测试**，不是对外卖 agent。
- 产品形状：纯函数引擎 + `node --test` + 静态页。

### N4 公开进度必须可核对

- 支持：主站计数、013 目录、README 表、X 复盘。
- 反复：GitHub 滞后线上是这次最大事故。
- 产品形状：`catalog.json` + check 脚本 + CI。不是 CMS。

### N5 品牌戳重复劳动

- 支持：每站 og/favicon 复制；主站 OG 曾落后编号。
- 反复：related interests「品牌资产」。
- 产品形状：dry-run 生成器（`lab/brand-stamp`），不接设计云。

## 不需要（写清楚，避免做成无关 SaaS）

- **多租户 SaaS / 登录体系 / 订阅收费后台。** 一个人的公开作品集，没有第二客户。
- **真实交易、转账、交易所 API 下单、跟单。** 红线。004/005/grid 停在纸面。
- **生产邮件群发、未授权发 X、自动改东京机。** 红线。发布是人 rsync。
- **通用 ESP32/3D 家居助手云平台。** 兴趣有，本仓零项目支持，**不到 ≥2**。先做设计笔记，不要开云。
- **第二套预测市场终端。** 004+005 已占坑；再做必须是不同切口（如纸面网格，已放 lab）。
- **把 011 做成移民中介。** 清单够用；法律意见不是产品。
- **TypeScript 大重构 / 上框架。** 作者底线是 HTML+Vanilla。工业化补测试与门，不换栈。
